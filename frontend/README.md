# فرانت‌اند — راهنمای اجرا

## ۱. راه‌اندازی اولیه (فقط یک‌بار)

```powershell
cd frontend
npm install
```

اگه پیام «running scripts is disabled» گرفتی (چون `npm` زیرِ پوست خودش یه اسکریپت پاورشلی صدا می‌زنه)، یکی از این دو راه:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
یا اگه سیاست‌های سیستم حتی همینم قبول نکرد، به‌جای `npm ...` همیشه `npm.cmd ...` بزن (نسخه‌ی cmd همون دستور، اصلاً درگیر این محدودیت نمی‌شه).

---

## ۲. اجرای سرور توسعه

```powershell
npm run dev
```

پیش‌فرض روی `http://127.0.0.1:5173` بالا میاد.

نکته‌ی مهم: این سرور برای رسیدن به بک‌اند، مسیرهای `/api/...` رو خودش (سمت سرور، نه توی مرورگر) به `http://127.0.0.1:8000` پراکسی می‌کنه (نگاه کن [vite.config.ts](vite.config.ts)) — یعنی قبلش باید بک‌اند هم روشن باشه ([راهنمای بک‌اند](../backend/README.md)، بخش ۲).

### تست بدون تلگرام (مستقیم توی مرورگر)

چون این اپ قراره داخل تلگرام باز بشه، به‌طور معمول نیاز به initData واقعی از تلگرام داره. ولی برای توسعه‌ی روزمره، اگه مستقیم توی مرورگر (نه داخل تلگرام) بازش کنی، خودش به‌طور خودکار یه initData آزمایشی از بک‌اند می‌گیره (نگاه کن [src/lib/api.ts](src/lib/api.ts)) — یعنی **نیازی به تانل یا تلگرام واقعی برای توسعه‌ی روزمره نیست**:

1. بک‌اند رو با `ENABLE_DEV_TOOLS=true` بالا بیار.
2. فرانت‌اند رو بالا بیار (همین دستور بالا).
3. مستقیم `http://127.0.0.1:5173` رو توی مرورگر باز کن.

تست واقعی داخل خودِ تلگرام (initData واقعی، ظاهر واقعی مینی‌اپ، تم تلگرام، پرداخت استارز) فقط وقتی لازمه که بخوای رفتار مخصوص خودِ تلگرام رو ببینی — اون‌جا [راهنمای اجرای کامل با تانل](../docs/LOCAL_DEV.md) رو ببین.

## ۴. ساخت نسخه‌ی نهایی (build)

```powershell
npm run build
```

خروجی توی `frontend/dist/` قرار می‌گیره. برای پیش‌نمایش همون خروجی: `npm run preview`

## ساختار پوشه‌ها

```
frontend/
  src/
    lib/
      api.ts      تنها نقطه‌ی ارتباط با بک‌اند — initData رو خودکار مدیریت می‌کند
      types.ts    شکل داده‌های برگشتی از بک‌اند (هم‌گام نگه‌داشته‌شده با schemas بک‌اند، دستی)
    App.tsx       صفحه‌ی فعلی (فقط تست اتصال؛ صفحات بیشتر بعداً اضافه می‌شوند)
    main.tsx      نقطه‌ی ورود، بسته‌بندی‌شده با AppRoot کیت رابط کاربری تلگرام
  vite.config.ts  تنظیمات پراکسی به بک‌اند + تنظیمات تست (Vitest)
```
