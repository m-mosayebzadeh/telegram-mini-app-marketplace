پوشه‌ی کاوشِ طراحی. **هیچ وابستگی‌ای به محصول ندارد و هیچ فایلی از آن را تغییر نمی‌دهد.**
کاملاً قابلِ حذف است. شرحِ کامل در `docs/TECHNICAL_REQUIREMENTS.md` بخش‌های ۲۲ و ۲۳.

## `prototype/` — مسیرِ فعلی: Cosmos / Orbit

نمونه‌ی زنده‌ی صفحه‌ی جهان. اجرا:

```
node design-exploration/prototype/serve.mjs
```

سه آدرس چاپ می‌کند: خودِ رایانه، `10.0.2.2:5180` برای شبیه‌سازِ اندروید،
و آی‌پیِ شبکه برای گوشیِ واقعی روی همان وای‌فای.

- `cosmos-world.html` — کلِ نمونه در یک فایلِ خودکفا، با توضیحِ هر تصمیم در خودِ کد
- `serve.mjs` — سرورِ ایستای کوچک، بدونِ هیچ وابستگی
- `fonts/` — قلم‌ها کنارِ اپ، چون سرورِ گوگل از ایران قابلِ اتکا نیست

داده ساختگی و بذردار است: هر بار همان جهان بالا می‌آید تا قضاوت ممکن باشد.
