# شالوده — توکن‌ها

همه‌ی مقادیر بصری محصول اینجا تعریف می‌شوند. هیچ کامپوننتی حق ندارد عدد یا رنگ
خام بنویسد؛ فقط توکن معنایی می‌خواند.

## دو لایه‌ی توکن

1. **توکن پایه** — مقدار خام، بدون معنا (`--ember-500`, `--space-4`).
   هیچ کامپوننتی مستقیم نمی‌خواندشان.
2. **توکن معنایی** — معنا، نه ظاهر (`--color-surface`, `--color-text-2`).
   **تنها لایه‌ای که کامپوننت‌ها اجازه دارند بخوانند.**

تم تیره و روشن فقط *مقدارِ* توکن‌های معنایی را عوض می‌کنند — نه نامشان، نه
ساختار هیچ کامپوننتی.

| توکن | تیره | روشن | کاربرد |
|---|---|---|---|

> سفید روی `#FF6B3D` فقط ۲.۸:۱ کنتراست دارد و رد می‌شود؛ متن تیره ۶.۶:۱ می‌دهد.
> این یک قانون سیستمی است، نه سلیقه.

### قواعد رنگ

- **رنگ هرگز تنها حامل معنا نیست.** همیشه با آیکون، برچسب، وزن یا جایگاه همراه شود.
- کنتراست حداقل: متن معمولی ۴.۵:۱، متن بزرگ و مرز رابط ۳:۱. همه‌ی مقادیر بالا
  بررسی شده‌اند.
- روی عکس، متن سفید مجاز است — به‌شرط داشتن اسکریم تیره یا `drop-shadow`.
  اسکریم روی عکس **کارکردی** است، نه تزئینی؛ تنها گرادیانت مجاز در محصول.

## تایپوگرافی

فونت: **Vazirmatn** — پوشش کامل فارسی و لاتین، از Google Fonts، به‌صورت
غیرمسدودکننده بارگذاری می‌شود.

```
--font: 'Vazirmatn', system-ui, 'Segoe UI', Roboto, sans-serif;
```

| نقش | اندازه / ارتفاع خط | وزن | کاربرد |
|---|---|---|---|
| `display` | ۲۸ / ۳۴ | ۷۰۰ | عدد موجودی، تک‌عدد بزرگ صفحه |
| `title` | ۲۲ / ۲۸ | ۷۰۰ | عنوان تب، نام در پروفایل |
| `heading` | ۱۸ / ۲۴ | ۶۰۰ | عنوان سکشن، عنوان پیشنهاد |
| `body` | ۱۵ / ۲۶ | ۴۰۰ | متن اصلی، توضیحات |
| `body-md` | ۱۵ / ۲۶ | ۵۰۰ | متن با تأکید، نام در لیست |
| `label` | ۱۳ / ۱۸ | ۶۰۰ | برچسب فیلد، برچسب چیپ |
| `caption` | ۱۲ / ۱۶ | ۴۰۰ | زمان، توضیح کمکی، متن زیر آیکون |

### قواعد

- **هیچ مقدار نیم‌پیکسلی.** اندازه‌ی جدید = نقش جدید با دلیل مستند.
- ارتفاع خطِ `body` عمداً ۱.۷۳ است — فارسی به فضای عمودی بیشتری از لاتین نیاز
  دارد. این عدد را برای «جمع‌وجورتر شدن» کم نکن.
- هر عددی که در ستون مقایسه می‌شود (قیمت، موجودی، تعداد) باید
  `font-variant-numeric: tabular-nums` داشته باشد.
- حداکثر دو وزن در یک صفحه کار واقعی انجام دهند.
- متن مخلوط فارسی و لاتین (نام کاربری، مبلغ) باید جداسازی جهت داشته باشد تا
  بصری جابه‌جا نشود.

## فاصله‌گذاری

مقیاس با پایه‌ی ۴. **هیچ مقداری بین پله‌ها نیست.**

```
--space-1: 4px     --space-5: 20px     --space-10: 40px
--space-2: 8px     --space-6: 24px     --space-12: 48px
--space-3: 12px    --space-8: 32px     --space-16: 64px
--space-4: 16px
```

قواعد ثابت:

- حاشیه‌ی افقی صفحه: `--space-5` (۲۰px)
- فاصله‌ی بین آیتم‌های یک لیست: جداکننده، نه فاصله
- فاصله‌ی بین سکشن‌ها: `--space-6` تا `--space-8`
- فاصله داخل یک بلوک: `--space-3` تا `--space-4`
- گروه‌بندی با **مجاورت** انجام می‌شود: چیزهای مرتبط باید واقعاً به هم نزدیک‌تر
  از چیزهای نامرتبط باشند.

## شعاع گوشه

چهار پله. شعاع اندازه‌ی عنصر را بیان می‌کند، نه تزئین را.

```
--radius-sm: 8px     دکمه‌های کوچک، چیپ مربعی، تصویر کوچک
--radius-md: 12px    دکمه‌ی اصلی، بلوک اطلاعات، ورودی
--radius-lg: 16px    کارت محتوا، عکس بزرگ
--radius-xl: 24px    لبه‌ی بالای شیت
--radius-full: 999px فقط آواتار، چیپ فیلتر، بج شمارنده
```

**همه‌چیز قرص نمی‌شود.** اگر شعاع همه‌جا یکسان باشد، دیگر هیچ اطلاعاتی منتقل
نمی‌کند.

## ارتفاع و سایه

**پیش‌فرض: بدون سایه.** سایه فقط برای چیزی که واقعاً شناور است.

```
--shadow-sheet: 0 -8px 32px rgba(0,0,0,0.35)   /* روشن: 0 -8px 32px rgba(0,0,0,0.10) */
--shadow-float: 0 6px 20px rgba(0,0,0,0.30)    /* روشن: 0 6px 20px rgba(0,0,0,0.08) */
```

- سایه‌ی رنگی ممنوع است. `glow` ممنوع است.
- جدا کردن دو سطح با مرز ۱ پیکسلی انجام می‌شود، نه با سایه.
- اگر یک عنصر هم مرز دارد هم پس‌زمینه‌ی متفاوت، یکی از آن دو زائد است.

## حرکت

```
--motion-fast: 150ms    بازخورد لمس، تغییر حالت
--motion-base: 200ms    گذار بین صفحات، ظاهر شدن لیست
--motion-sheet: 280ms   باز و بسته شدن شیت
--ease: cubic-bezier(0.2, 0.8, 0.2, 1)
```

- فقط `transform` و `opacity` انیمیت می‌شوند.
- حرکت باید **رابطه‌ی مکانی** را توضیح دهد: صفحه از لبه می‌آید، شیت از پایین
  بالا می‌آید، بستن دقیقاً برعکس باز شدن است.
- هیچ حرکت تزئینی، هیچ حلقه‌ی بی‌پایان، هیچ چیزی که تعامل را عقب بیندازد.
- `prefers-reduced-motion` رعایت می‌شود.

## آیکون

- یک ست واحد، خطی (outline)، شبکه‌ی ۲۴×۲۴، ضخامت خط ثابت **۱.۹**.
- اندازه‌های مجاز: ۱۶ / ۱۸ / ۲۰ / ۲۲ / ۲۴.
- رنگ همیشه `currentColor` — آیکون رنگ خودش را ندارد.
- **هرگز ایموجی به‌جای آیکون.**
- آیکون‌های جهت‌دار (فلش، شورون) زیر `dir="rtl"` آینه می‌شوند.

### دراپ — واحد پول

نشان اختصاصی محصول: یک قطره با هسته‌ی شعله. زیر ۲۰ پیکسل فقط سیلوئت بیرونی
کشیده می‌شود؛ هسته در اندازه‌های کوچک ناخوانا می‌شود.

```
M12 2.8C12 2.8 5.9 9.6 5.9 14a6.1 6.1 0 0 0 12.2 0c0-4.4-6.1-11.2-6.1-11.2Z
```

همیشه پر (`fill`) با `--color-accent`، هرگز خطی. کنار عدد می‌آید، نه به‌جای آن.
