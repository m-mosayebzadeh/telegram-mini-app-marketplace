# اجرای کامل محلی — بک‌اند + فرانت‌اند + تست داخل تلگرام واقعی

این سند مکمل [backend/README.md](../backend/README.md) و [frontend/README.md](../frontend/README.md) است — اونا نحوه‌ی اجرای هرکدوم رو جدا توضیح می‌دن؛ این‌جا فقط قدم‌های اضافه‌ای هست که برای دیدن مینی‌اپ **داخل خودِ تلگرام واقعی** لازمه (نه برای توسعه‌ی روزمره — برای اون، بخش «تست بدون تلگرام» در [frontend/README.md](../frontend/README.md) کافیه و نیازی به هیچ‌کدام از مراحل زیر نیست).

---

## ۱. چرا اصلاً به تانل نیاز داریم

تلگرام فقط به یک آدرس اینترنتیِ **واقعی و با HTTPS معتبر** اجازه می‌ده به‌عنوان آدرس مینی‌اپ ثبت بشه — نه `http://127.0.0.1`. برای اینکه بدون خرید سرور و دیپلوی واقعی، بتونیم مینی‌اپی که روی سیستم خودمون در حال اجراست رو داخل تلگرام باز کنیم، یک تانل (یک آدرس عمومی موقت که ترافیک رو به سیستم محلی برمی‌گردونه) لازمه.

**فقط سرور فرانت‌اند (ویت، پورت ۵۱۷۳) تانل می‌شود، نه بک‌اند.** فرانت‌اند خودش مسیرهای `/api/...` رو سمت سرور به بک‌اند محلی (پورت ۸۰۰۰) پراکسی می‌کنه (نگاه کن [frontend/vite.config.ts](../frontend/vite.config.ts))، پس تلگرام فقط با یک آدرس (همون تانل) کار داره و نیازی به تانل کردن بک‌اند به‌صورت جدا نیست.

## ۲. ابزار تانل: ngrok

اول امتحان کردیم کلادفلر (که بدون نیاز به حساب کاربری کار می‌کنه)، ولی روی این شبکه پورت لازمش (۷۸۴۴، هم UDP هم TCP) کاملاً بسته بود — به احتمال زیاد یک محدودیت سطح شبکه/ISP، نه تنظیمات ویندوز (با تست مستقیم شبکه هم تایید شد). به همین دلیل از **ngrok** استفاده می‌کنیم که روی پورت استاندارد ۴۴۳ کار می‌کنه.

### ۲.۱. نصب (یک‌بار)

```powershell
winget install --id Ngrok.Ngrok -e
```

### ۲.۲. ساخت حساب و تنظیم توکن (یک‌بار)

ngrok دیگه بدون حساب کاربری کار نمی‌کنه:

1. ثبت‌نام رایگان: https://dashboard.ngrok.com/signup
2. برداشتن توکن: https://dashboard.ngrok.com/get-started/your-authtoken
3. تنظیم توکن روی سیستم (فقط یک‌بار لازمه، بعدش سیستم به‌خاطر می‌سپاره):
   ```powershell
   ngrok config add-authtoken TOKEN_خودت
   ```

⚠️ این توکن هم مثل توکن بات تلگرام یک مقدار محرمانه‌ست — مستقیم داخل ترمینال خودت وارد کن، نه جایی که به اشتراک گذاشته می‌شه.

### ۲.۳. اجرا

هر بار که خواستی تست کنی، به همین ترتیب (هرکدوم توی یک ترمینال جدا):

```powershell
# ترمینال ۱ — بک‌اند (backend/README.md بخش ۲)
cd backend
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --reload

# ترمینال ۲ — فرانت‌اند (frontend/README.md بخش ۲)
cd frontend
npm run dev

# ترمینال ۳ — تانل، به فرانت‌اند وصل می‌شود نه بک‌اند
ngrok http 5173
```

ngrok یک آدرس مثل `https://xxxx-xx-xx-xx-xx.ngrok-free.app` نشون می‌ده — همین آدرس رو برای مرحله‌ی بعد لازم داری.

## ۳. ثبت آدرس مینی‌اپ نزد تلگرام

این قدم رو باید خودت مستقیم توی تلگرام با دستیار ساخت ربات (BotFather) انجام بدی:

1. توی تلگرام به `@BotFather` پیام بده.
2. `/mybots` → بات خودت (`Dating_soheil_test_bot`) رو انتخاب کن.
3. **Bot Settings** → **Menu Button** (یا **Configure Mini App** بسته به نسخه‌ی رابط BotFather) → آدرس ngrok مرحله‌ی قبل رو وارد کن.
4. حالا از داخل چت با باتِ خودت، دکمه‌ی منو (یا لینک مینی‌اپ) رو بزن — باید همون چیزی که روی `127.0.0.1:5173` می‌بینی رو داخل تلگرام هم ببینی، این‌بار با initData واقعی.

⚠️ **آدرس ngrok در نسخه‌ی رایگان هر بار که دوباره اجراش کنی عوض می‌شه** — یعنی هر بار باید همین قدم (۳) رو دوباره با آدرس جدید تکرار کنی.

## ۴. نکته‌ی امنیتی مهم درباره‌ی dev tools

`ENABLE_DEV_TOOLS=true` مسیرهای مخصوص توسعه (مثل شارژ آزمایشی کیف پول) رو فعال می‌کنه که هیچ‌وقت نباید از بیرون قابل‌دسترس باشن. این مسیرها با یک بررسی «فقط از localhost» محافظت می‌شن (نگاه کن [backend/app/dev/router.py](../backend/app/dev/router.py)) — چون معماری تانل روی فرانت‌اند تانل می‌شه نه بک‌اند، این بررسی ممکنه هر درخواستی رو که از طریق پراکسیِ فرانت‌اند می‌رسه اشتباهاً «محلی» تشخیص بده، حتی اگه واقعاً از طریق تانل و از بیرون اومده باشه.

راه‌حلی که اول به ذهن رسید (خوندن IP واقعیِ درخواست‌دهنده از یک هدر مخصوص) رد شد: چون وقتی خودمون هم از طریق تانل و تلگرام واقعی تست می‌کنیم، اون درخواست هم دقیقاً همون‌قدر «از بیرون» به نظر می‌رسه که درخواست یک غریبه — یعنی از روی IP نمی‌شه «خودمون» رو از یک غریبه جدا کرد.

**راه‌حل واقعی، بدون نیاز به هیچ تغییر کدی:**
- **همیشه وقتی تانل روشنه، `ENABLE_DEV_TOOLS=false` باشه.**
- هر کاری با مسیرهای dev لازم داری (initData تستی، شارژ آزمایشی کیف پول)، مستقیم به `127.0.0.1:8000` وصل شو یا از برونو استفاده کن — هیچ‌وقت از طریق آدرس تانل.
